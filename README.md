# Detect STT Streamlit App

A Streamlit app that uses `detect_stt_en.py` logic to detect audio language, transcribe speech, and translate to English.

## Setup

1. Open a terminal in `detect_stt_app`
2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Usage

1. Upload an audio file.
2. Click `Process Audio`.
3. View detected language, transcript, and English translation.
